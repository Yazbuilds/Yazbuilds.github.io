## What's here

- `index.html` — the whole site (HTML, CSS and JS in one file, no build step needed).

## Publishing this

1. Rename this repo to `yourusername.github.io` (replace with your actual GitHub username) — GitHub uses that exact name to auto-publish it as a website.
2. Upload `index.html` to the root of the repo.
3. In the repo, go to **Settings → Pages** and confirm the source is the `main` branch, root folder.
4. Your site goes live at `https://yourusername.github.io` within a minute or two.

## Updating content later

Everything lives in `index.html` — achievements, experience, competencies, education. When you tailor a CV for a specific job, update this file first so it stays the single source of truth, then pull tailored bullets from it into the job-specific CV.

Sections you'll most often touch:

- **Delivery scorecard** (top of page) — the four headline metric tiles.
- **`#achievements`** — the metric cards.
- **`#experience`** — the role timeline (add new roles at the top).
